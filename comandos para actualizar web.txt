Para actualizar tu aplicación en línea (Render) después de hacer cambios en tu computadora, abre la terminal en la carpeta de tu proyecto y ejecuta estos tres comandos, uno por uno:

1. Agrega todos los archivos nuevos o modificados:
git add .

2. Guarda los cambios con un mensaje que describa lo que hiciste (puedes cambiar el texto entre comillas):
git commit -m "Actualizacion de la app"

3. Sube los cambios a GitHub (esto hará que Render se actualice automáticamente en un par de minutos):
git push
